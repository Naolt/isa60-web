# ISA60 International Website

Website for [ISA60 International](https://isa60minethio.com), an interdenominational non-profit Christian ministry that equips local churches in Ethiopia through its Men of Honor and Women of Dignity programs.

**Live:** [isa60minethio.com](https://isa60minethio.com)

## My role

Freelance project (2024). I built the site end to end: pages for the organisation's story, programs, team, gallery and ways to get involved, plus a Sanity CMS studio so staff can update photos, videos and team profiles without touching code.

## Tech stack

Next.js (App Router) · React · TypeScript · Tailwind CSS · shadcn/ui · Sanity CMS · Framer Motion · Three.js (3D globe)

## Running locally

```bash
npm install
npm run dev   # http://localhost:3000, CMS studio at /studio
```
